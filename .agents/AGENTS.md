# A.M.F Band Website Project Rules

このワークスペース（A.M.F公式サイトプロジェクト）で作業を行う際は、以下のルールと設計思想を厳守してください。

## 1. コミュニケーション方針
- **言語設定**: ユーザーへの確認や質問、提案は常に「日本語」で行ってください。英語での技術的な専門質問を頻繁に行うのは避けてください。

## 2. アーキテクチャと保存設計
- **完全静的フロントエンド**: バックエンドサーバーは導入せず、完全な静的HTML/CSS/JSで構成します。
- **データ定義の分離**: すべてのコンテンツ（テキスト、メンバー情報、画像Base64、BGM等）は `config.js` に集約し、`app.js` で動的レンダリングします。
- **ビジュアルエディター（管理画面）**: `admin.html` / `admin.js` が `config.js` の書き出しを担います。
- **ローカルサーバー連携**: `netlify_helper.ps1`（`run_helper.bat`）がローカルHTTPサーバー（ポート3001）として動作し、直接保存と自動プッシュを仲介します。

## 3. デプロイとソース管理
- **GitHub Pagesデプロイ**: コード変更（HTML/CSS/JS/アセット）を行った際は、必ず GitHub リポジトリ（`origin/main`）にプッシュ（`git push origin main`）して変更を公開サイトにデプロイしてください。

## 4. 外部APIの選定基準
- **無料かつ安全性の確保**: 動的機能（ランキング、カウンター等）を実装する際は、アカウント登録不要でセキュリティ上のリスクがない無料のCORS対応API（例: 共有データベース `KVdb.io`、カウンター `Abacus API`）を採用してください。
